# 星枢手机版 v0.2.4（支持最长 5 分钟完整动态大厅背景 + 实测帧率音画校准）

## 更新内容

1. **解除大厅背景 20 秒 / 360 帧截断限制，支持最长 5 分钟（300 秒）完整播放**
   - 此前 `v0.2.3` 转码器将硬件解码限制在 `20 秒 / 360 帧`（兼容回退路径 `15 秒 / 180 帧`），且未按实际解码时间跨度校准 `fpsMilli`，导致长视频播放十秒多就提前从头循环。
   - `v0.2.4` 将单视频转码上限提升至 **300 秒（5 分钟） / 3550 帧**，并根据视频真实时长自动选择自适应分辨率与帧率（45 秒内 960×540@18fps，2 分钟内 854×480@15fps，4 分钟内 768×432@12fps，5 分钟内 720×406@~11.6fps）。
2. **磁盘流式 `.xsvid` 封装 + 帧率/伴音精准校准**
   - `XsvidWriter` 新增 `writePackageFromRawStream(...)`，编码帧直接落盘流式封装（内存占用仅约 2 MB，避免长视频 OOM）。
   - `AndroidLobbyVideoTranscoder` 按视频实际首尾时间戳动态校准 `fpsMilli`，并在视频解码完成后同步抽取等长完整 `.m4a` 伴音轨；导完提示直接展示转码后的真实总秒数与帧数。
3. **运行库说明**
   - 已安装的 **`1.0.0-android-preview8.62`** 运行库本身已支持最高 3600 帧与 64 MB 伴音的磁盘流式读取，升级至启动器 `v0.2.4` 后重新导入一次 `.mp4` 即可完整播放（无需重新安装游戏核心）。
